Principles

  1. Content first. Code and the preview are the brightest, largest things on screen. Chrome recedes: panels sit one step above the window, controls one step above panels.
  2. One accent. The accent marks the primary action, focus and selection. Status colours (success, warning, error) are separate and never decorate.
  3. A 4 px grid. Every size, gap and padding is a multiple of 4. Controls come in three heights. Nothing is sized by eye.
  4. Contrast is checked, not assumed. Text reaches 4.5:1 on its surface, UI edges and icons 3:1. The table below recomputes this for the current theme.
  5. The timeline is a palette. Six lane colours separate animation kinds. They stay legible on the editor surface in both light and dark themes.

Colour roles

Each role has one job. The app derives hover, pressed, selection and soft status fills from these values, so a theme only supplies the base colours.

Buttons

Sizes

Default is medium. Small is for dense toolbars and the inspector, large for dialog footers. Text buttons are at least 72 px wide with 12 px side padding. Icon buttons are square.
